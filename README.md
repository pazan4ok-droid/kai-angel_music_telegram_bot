# 🦇 Telegram VIPERR Media Assistant Bot

A fully asynchronous Telegram bot designed as a comprehensive music encyclopedia and interactive playlist guide for the alternative rap duo **VIPERR (Kai Angel & 9mice)**. It dynamically routes open-source streaming traffic via SoundCloud.

## 🚀 Key Features
- **Dual-Artist Architecture:** Features branched sub-menus separating solo discographies for both Kai Angel and 9mice, alongside a dedicated section for collaborative anthems.
- **Curated Vibe Playlists:** Detailed tracklists with granular sub-genres (Opium-rap, Rage, Synth-pop, Industrial Rock, and Ambient focus tracks).
- **Trilogy Drop Tracker:** Integrated active links set up for the highly anticipated final album installment.
- **Production Insights:** High-utility track descriptions highlighting specific beatmakers (e.g., F1LTHY, weluvneon) and sound design elements (e.g., heavy distortion, live electric guitars).
- **Proactive Network Architecture:** Implements a custom Cloudflare Workers server proxy to guarantee regional connection stability without forcing end-users to change local device configurations.

## 🛠 Tech Stack
- **Language:** Python 3.13
- **Framework:** Aiogram 3.x (Asynchronous Telegram Bot API)
- **Deployment & Proxying:** Serverless **Cloudflare Workers** (JavaScript ES6 framework)
- **Data Structuring:** Deeply nested Python Dictionaries (`dict`) for instant lookup caching.
